# ACP-102: Add goal lifecycle services

## Problem
Goal data is not useful unless the system can create, update, pause, resume, and close it consistently.

## Scope
- Implement goal lifecycle services.
- Add history event appends for lifecycle changes.
- Keep lifecycle transitions explicit and testable.

## Out of Scope
- Planner logic.
- UI work beyond service consumption.

## Acceptance Criteria
- Goal lifecycle transitions are represented by service methods.
- Lifecycle changes append history entries.
- Goal status changes are easy to inspect in tests.

## Dependencies
- ACP-101

## Validation
- Unit tests for lifecycle transitions and history appends.
