# RIM-601: Implement worktree lifecycle service

## Problem
Risky or long-running workflows require isolation, but there is no managed worktree lifecycle.

## Scope
- Implement create, reuse, and cleanup lifecycle for isolated worktrees.
- Track mapping of runs to worktree metadata.
- Add cleanup safeguards and orphan detection.

## Out of Scope
- Cloud or remote execution environments.
- Multi-repository orchestration.

## Acceptance Criteria
- Worktree can be provisioned and cleaned up for isolated runs.
- Repeated runs do not leak orphaned worktree state.
- Errors in setup/cleanup are surfaced with actionable guidance.

## Dependencies
- RIM-303

## Validation
- Integration tests for provision and cleanup success/failure.
- Manual checks for repeated isolated run cycles.
