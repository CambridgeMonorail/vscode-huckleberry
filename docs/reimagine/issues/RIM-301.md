# RIM-301: Implement runner process and IPC contract

## Problem
The extension cannot execute durable workflows without a dedicated runner and explicit communication protocol.

## Scope
- Implement local runner process lifecycle.
- Define IPC contract for start, status, cancel, and event streaming.
- Add extension client wiring for runner handshake and reconnect.

## Out of Scope
- Full state-machine logic.
- Agent provider implementation.

## Acceptance Criteria
- Extension can start a run request via IPC without blocking UI.
- Runner streams status/events back to extension client.
- Runner lifecycle failures surface clear user-facing errors.

## Dependencies
- RIM-201

## Validation
- Integration test for runner startup and basic run command.
- Manual smoke test from extension host showing start and status updates.
