# RIM-502: Build Evidence Explorer

## Problem
Evidence is hard to inspect quickly without a dedicated explorer organized by run and step provenance.

## Scope
- Implement Evidence Explorer view grouped by run, step, and artifact type.
- Support artifact categories: output, diff, screenshot, diagnostic, test result.
- Add open and reveal actions for artifacts.

## Out of Scope
- Full rich preview renderers for every artifact type.
- External artifact storage.

## Acceptance Criteria
- Evidence Explorer lists artifacts with provenance context.
- Users can open artifacts from explorer with one action.
- Missing or stale artifacts are clearly marked.

## Dependencies
- RIM-304

## Validation
- UI tests for grouping and interaction behavior.
- Manual inspection with mixed artifact fixtures.
