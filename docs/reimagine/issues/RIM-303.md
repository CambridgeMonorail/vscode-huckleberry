# RIM-303: Add command step executor

## Problem
Workflows cannot deliver value until deterministic command steps execute and capture outputs.

## Scope
- Implement command step execution using child processes.
- Capture exit code, stdout, stderr, duration, and timeout outcome.
- Emit evidence artifacts and step result events.

## Out of Scope
- Agent step execution.
- Visual diff/screenshot evidence types beyond command output.

## Acceptance Criteria
- Command steps execute in configured working context.
- Output artifacts are persisted and linked to step evidence metadata.
- Failures and timeouts generate explicit stop or retry behavior per policy.

## Dependencies
- RIM-301, RIM-302

## Validation
- Integration test with passing and failing command fixtures.
- Timeout test confirms cancellation and event emission.
