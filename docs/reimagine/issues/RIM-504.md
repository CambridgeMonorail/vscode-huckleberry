# RIM-504: Add run summary report generation

## Problem
Teams need concise reproducible outcome summaries without manually parsing full event timelines.

## Scope
- Generate end-of-run summary from persisted event stream.
- Include outcome, attempts, stop reason, and unresolved items.
- Support machine-readable and human-readable summary output.

## Out of Scope
- Advanced analytics dashboards.
- External report publishing integrations.

## Acceptance Criteria
- Summary output is deterministic for a given event stream.
- Summary includes terminal state, key evidence references, and unresolved items.
- Summary is retrievable after reload.

## Dependencies
- RIM-304

## Validation
- Snapshot tests on known event fixtures.
- Manual check with success, failure, and cancelled runs.
