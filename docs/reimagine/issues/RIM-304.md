# RIM-304: Persist runs, events, and evidence metadata

## Problem
Without persistence, run inspection, crash recovery, and evidence auditability are unreliable.

## Scope
- Implement append-only event persistence for run lifecycle.
- Persist evidence metadata index and artifact references.
- Add read model helpers for run status reconstruction.

## Out of Scope
- Full analytics and telemetry dashboarding.
- Cloud-backed storage.

## Acceptance Criteria
- Completed and interrupted runs can be reconstructed after extension reload.
- Evidence metadata can be queried by run and step.
- Persistence failures are handled safely without corrupting event history.

## Dependencies
- RIM-302

## Validation
- Restart test verifies run reconstruction from persisted events.
- Corruption-path test verifies graceful failure behavior.
