# RIM-201: Define workflow schema v1

## Problem
Without a canonical schema, workflow definitions will drift and validation behavior will be inconsistent across parser, UI, and runner.

## Scope
- Define workflow schema v1 with required top-level fields.
- Define step model and supported step types for initial scope.
- Define constraints for identifiers, retries, and execution options.
- Publish TypeScript types aligned with schema.

## Out of Scope
- Advanced step types beyond planned v1 scope.
- Runtime runner implementation.

## Acceptance Criteria
- JSON Schema v1 exists and validates baseline workflow files.
- TypeScript contract file aligns with schema fields.
- Schema validation catches malformed IDs, missing required fields, and invalid step type payloads.

## Dependencies
- RIM-003

## Validation
- Validate a known-good sample file successfully.
- Validate known-bad fixtures and confirm expected error categories.
