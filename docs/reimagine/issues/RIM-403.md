# RIM-403: Add agent step node type with explicit constraints

## Problem
Unbounded agent execution risks scope creep, unsafe changes, and non-deterministic loops.

## Scope
- Add `agent` node type to workflow model and runner execution path.
- Support constraints: allowed paths, max files changed, max turns.
- Enforce constraint violations as explicit stop outcomes.

## Out of Scope
- Parallel multi-agent orchestration.
- Automatic policy authoring.

## Acceptance Criteria
- Agent step executes only through configured constraints.
- Constraint breaches terminate or fail run with explicit reason.
- Constraint config is validated at parse time where possible.

## Dependencies
- RIM-401, RIM-201

## Validation
- Tests for path scope restriction, max files changed, and max turns.
- Negative tests confirm explicit stop reasons for violations.
