# RIM-205: Add starter workflow templates

## Problem
First-time adoption is slow without valid starter loops users can run and modify immediately.

## Scope
- Add command to scaffold baseline workflow templates.
- Provide templates for typecheck, test, and lint loops.
- Ensure generated files target schema v1 and pass validator.

## Out of Scope
- Full visual workflow authoring.
- Organization template marketplace support.

## Acceptance Criteria
- Template command creates files in expected loop directory.
- Generated templates validate successfully against schema and semantic checks.
- Template docs explain intended usage and required inputs.

## Dependencies
- RIM-201, RIM-203

## Validation
- Create templates in a clean workspace and validate output.
- Automated tests confirm generation path and file contents.
