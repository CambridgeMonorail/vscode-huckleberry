# RIM-604: Add diff evidence for isolated runs

## Problem
Isolated execution is not reviewable without first-class diff evidence tied to each run.

## Scope
- Capture run-level diff artifacts for isolated runs.
- Optionally capture step-level diff snapshots where configured.
- Link diff artifacts into timeline and evidence explorer.

## Out of Scope
- Semantic code review automation.
- PR auto-creation.

## Acceptance Criteria
- Isolated runs include at least one run-level diff artifact.
- Diff evidence is discoverable from run details and evidence explorer.
- Missing diff generation failures are surfaced as explicit warnings/errors.

## Dependencies
- RIM-602, RIM-304

## Validation
- Integration tests for diff generation and artifact linkage.
- Manual check confirms diff files are inspectable.
