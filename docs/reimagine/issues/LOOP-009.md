# LOOP-009: Add iteration supervision and intervention UX

- Priority: P1
- Status: Planned
- Milestone: 2 — Product vertical slice
- Depends on: LOOP-004, LOOP-007

## Outcome

The Runs experience explains the feedback loop rather than exposing only a flat technical event stream.

## Acceptance criteria

- Runs are grouped into iterations.
- Each iteration shows start reason, actor status and claim, measured delta, verifier result, decision, and remaining budgets.
- Users can cancel an active actor or verifier.
- Paused runs show why they paused and which actions are available.
- Claims and evidence are visually distinct.
- Evidence artifacts remain reachable from the relevant iteration.
