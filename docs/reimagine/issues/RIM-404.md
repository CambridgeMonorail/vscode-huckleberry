# RIM-404: Implement repair loop semantics

## Problem
Repair behavior is inconsistent without a formal pattern for check-fail-repair-recheck cycles.

## Scope
- Implement deterministic repair loop behavior between failed deterministic checks and agent repair steps.
- Enforce retry budgets and timeout budgets across repair cycles.
- Record attempt metadata for each repair iteration.

## Out of Scope
- Heuristic autonomous loop discovery.
- Dynamic workflow mutation at runtime.

## Acceptance Criteria
- Failed checks can trigger configured repair and deterministic re-check flow.
- Retry limits and timeout budgets are always enforced.
- Timeline shows attempt count and final exhaustion or success outcome.

## Dependencies
- RIM-403, RIM-303

## Validation
- Integration tests for success-after-repair and exhausted-retry scenarios.
- Event log assertions verify attempt metadata and terminal reason.
