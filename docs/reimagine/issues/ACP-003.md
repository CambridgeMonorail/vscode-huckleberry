# ACP-003: Define migration posture

## Problem
Without a migration posture, the team could accidentally break the current workflow substrate while building the goal-first model.

## Scope
- Document what existing loops, runs, and evidence remain valid.
- Document what is repurposed into the goal-first model.
- Document what task-era concepts are expected to be deprecated later.

## Out of Scope
- Any runtime refactor.
- Deleting legacy features.

## Acceptance Criteria
- Migration note states what is retained, repurposed, and deprecated.
- The note identifies user-visible continuity guarantees.

## Dependencies
- ACP-001

## Validation
- Compare the migration note to current extension capabilities.
