# RIM-401: Introduce AgentAdapter abstraction

## Problem
Direct coupling between workflow engine and provider SDKs will make reliability and provider evolution hard to manage.

## Scope
- Define provider-neutral `AgentAdapter` interface.
- Implement adapter registry and availability checks.
- Wire runner to use adapter interface only for agent step execution.

## Out of Scope
- Full provider-specific implementation details beyond stubs.
- Multi-provider routing policy.

## Acceptance Criteria
- Runner compiles and executes command-only workflows with no active adapter.
- Agent step path invokes adapter contract, not provider SDK directly.
- Adapter capability or availability failures are surfaced clearly.

## Dependencies
- RIM-303

## Validation
- Unit tests for adapter contract and registry behavior.
- Integration test verifies command-only workflows remain functional when adapter disabled.
