# RIM-305: Build Runs UI timeline

## Problem
Users cannot diagnose workflow behavior without a clear run timeline and step-level outcomes.

## Scope
- Implement run list and run details timeline UI.
- Show step status, timestamps, duration, and key evidence links.
- Add live update handling from runner event stream.

## Out of Scope
- Full Evidence Explorer implementation.
- Complex visual graph rendering.

## Acceptance Criteria
- Runs view displays current and historical runs.
- Timeline updates in near real-time for active runs.
- Selecting a step shows relevant outputs and stop reason where applicable.

## Dependencies
- RIM-302, RIM-304

## Validation
- Manual run-through with passing and failing loops.
- UI tests for timeline rendering and status updates.
