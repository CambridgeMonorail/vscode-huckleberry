# ACP-001: Define control-plane vocabulary

## Problem
The new roadmap needs a shared language before implementation can stay consistent across docs, services, and UI.

## Scope
- Define the canonical meanings of Goal, Planner, Workflow, Skill, Agent, Policy, Evidence, Claim, and Reflection.
- Record any key lifecycle terms needed by later stages.
- Link the vocabulary to the staged implementation plan and tracker.

## Out of Scope
- Runtime code changes.
- Persistence or UI implementation.

## Acceptance Criteria
- Vocabulary is written down in a repo doc.
- Terms are used consistently in the plan, tracker, and follow-up issue specs.
- Ambiguous or duplicate terms are called out explicitly.

## Dependencies
- None

## Validation
- Review the vocabulary against the staged plan and requirements.
