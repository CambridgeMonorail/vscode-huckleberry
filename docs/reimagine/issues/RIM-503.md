# RIM-503: Improve diagnostics and deep-link integration

## Problem
Failed runs are slow to triage when users cannot jump directly from timeline entries to root evidence.

## Scope
- Add deep links from run timeline to Problems, tests, diffs, and logs.
- Normalize link metadata in run events.
- Ensure broken links degrade with clear fallback messaging.

## Out of Scope
- Full IDE diagnostics pipeline redesign.
- Custom test explorer replacement.

## Acceptance Criteria
- Failed steps expose direct navigation actions to relevant diagnostics/evidence.
- Link targets open correctly in common failure scenarios.
- Fallback messaging is shown when target is unavailable.

## Dependencies
- RIM-305

## Validation
- Manual failure scenarios verify navigation paths.
- Automated tests for link metadata generation.
