# ACP-401: Add skills registry

## Problem
The planner needs a discoverable catalog of reusable skills.

## Scope
- Implement repo-local skill discovery and registration.
- Define registry APIs for listing and selecting skills.
- Leave extension points for org and third-party skill sources.

## Out of Scope
- Marketplace integration.
- Skill execution runtime details.

## Acceptance Criteria
- Repo skills can be discovered and listed.
- Registry output is usable by planner selection logic.
- Registry architecture supports future providers.

## Dependencies
- ACP-201

## Validation
- Tests for skill discovery and registry outputs.
