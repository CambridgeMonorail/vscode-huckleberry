# ACP-704: Define release gates

## Problem
The roadmap needs explicit go/no-go criteria tied to evidence before release decisions can be trusted.

## Scope
- Define release gate criteria across automated tests, manual validation, and documentation completeness.
- Define required evidence to pass each gate.
- Align release gates with tracker stage exit criteria.

## Out of Scope
- Publishing automation implementation.
- Marketplace listing workflow.

## Acceptance Criteria
- Release gates are documented and auditable.
- Gate criteria map to tracker and validation artifacts.
- Decision outcomes can be recorded as go/no-go with rationale.

## Dependencies
- ACP-701, ACP-702, ACP-703

## Validation
- Review release gate checklist against available test and docs outputs.
