# ACP-502: Add plan and policy visibility

## Problem
Supervision requires visibility into current strategy and constraints, not just execution outcomes.

## Scope
- Surface planner outputs in goal detail or related views.
- Surface policy constraints and latest decisions.
- Provide direct links from blocked states to policy reasons.

## Out of Scope
- Authoring UI for policy configuration.
- Advanced visual graph rendering.

## Acceptance Criteria
- Users can see current plan and blocked reasons.
- Policy decisions are visible alongside impacted steps.
- Data updates as plan or policy changes occur.

## Dependencies
- ACP-201, ACP-301

## Validation
- Extension host tests for plan/policy visibility and update flows.
