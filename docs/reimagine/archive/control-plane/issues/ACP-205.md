# ACP-205: Bridge goal execution to current runner

## Problem
The new goal model needs an execution path before a full replacement runtime is complete.

## Scope
- Add a compatibility layer that maps goal plans to current runner workflows.
- Preserve existing run/evidence behavior during transition.
- Record mapping decisions for traceability.

## Out of Scope
- Full runtime rewrite.
- Deprecation of existing runner flows.

## Acceptance Criteria
- A planned goal can execute through the existing runner path.
- Execution traces remain linked to the parent goal.
- Existing workflow execution remains functional.

## Dependencies
- ACP-201, ACP-204

## Validation
- Integration tests for goal-to-runner execution mapping.
