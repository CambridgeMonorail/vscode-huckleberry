# ACP-403: Extend agent adapter model

## Problem
Single-path agent integration is insufficient for role-based orchestration.

## Scope
- Extend adapter boundaries for research, planning, implementation, review, and verification roles.
- Keep provider-specific behavior behind adapter interfaces.
- Add capability and availability checks by role.

## Out of Scope
- Direct provider coupling in planner or UI layers.
- Cost optimization heuristics.

## Acceptance Criteria
- Runtime can request agent work by role.
- Adapter interfaces remain provider-neutral.
- Availability failures are explicit and recoverable.

## Dependencies
- ACP-301, ACP-402

## Validation
- Tests for role routing and adapter fallback behavior.
