# ACP-301: Implement policy engine

## Problem
Autonomous actions need centralized governance to prevent unsafe or out-of-scope execution.

## Scope
- Implement policy decisions: allow, deny, require-approval, require-evidence.
- Enforce path, command, and tool boundaries before execution.
- Emit policy decision records for auditing.

## Out of Scope
- UI policy editors.
- Organization-wide policy federation.

## Acceptance Criteria
- Proposed actions are evaluated before execution.
- Unsafe actions can be denied or gated.
- Policy decision metadata is persisted.

## Dependencies
- ACP-201

## Validation
- Unit tests for policy decision outcomes and enforcement.
