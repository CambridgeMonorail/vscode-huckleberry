# ACP-501: Add Goal view and detail experience

## Problem
Users need a goal-first UI to supervise autonomous work without relying on chat history.

## Scope
- Add a Goal view listing active and historical goals.
- Add goal detail view for status, plan, progress, and history.
- Wire views to goal and progress services.

## Out of Scope
- Full visual redesign of all explorers.
- External web dashboards.

## Acceptance Criteria
- Users can inspect goals from the activity bar.
- Goal detail surfaces progress and history clearly.
- View state survives extension reload.

## Dependencies
- ACP-101, ACP-105

## Validation
- Extension host tests for view rendering and data hydration.
