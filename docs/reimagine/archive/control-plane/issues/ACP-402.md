# ACP-402: Define skill contract

## Problem
Skills need a standard contract so planner, policy, and runtime systems can consume them consistently.

## Scope
- Define contract fields for inputs, outputs, evidence, permissions, failure modes, and runtime limits.
- Validate skill definitions against the contract.
- Document versioning expectations.

## Out of Scope
- Provider-specific execution logic.
- Skill marketplace publishing.

## Acceptance Criteria
- Skill definitions can be validated.
- Contract includes all fields required by requirements.
- Contract supports policy evaluation inputs.

## Dependencies
- ACP-401

## Validation
- Contract validation tests with valid and invalid samples.
