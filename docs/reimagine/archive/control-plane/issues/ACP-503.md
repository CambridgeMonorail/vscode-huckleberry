# ACP-503: Integrate evidence navigation

## Problem
Supervisory UX is incomplete unless users can jump directly from goals and plans to supporting evidence.

## Scope
- Add deep links from goal and plan surfaces to evidence artifacts.
- Preserve existing run/evidence link behavior.
- Provide fallbacks for missing artifacts.

## Out of Scope
- Full-text evidence search.
- External evidence viewers.

## Acceptance Criteria
- Goal surfaces can open linked evidence artifacts.
- Missing artifacts show clear fallback messaging.
- Existing evidence explorer interactions continue to work.

## Dependencies
- ACP-302, ACP-303

## Validation
- Extension host tests for evidence deep-link behavior.
