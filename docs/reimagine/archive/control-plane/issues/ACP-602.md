# ACP-602: Deprecate task-era concepts

## Problem
Residual task-era wording and code paths create confusion and slow migration.

## Scope
- Identify remaining task-era user-facing concepts.
- Plan and execute controlled deprecations.
- Document deprecations and compatibility notes.

## Out of Scope
- Breaking removal without migration path.
- Non-related refactors.

## Acceptance Criteria
- Task-era references targeted for deprecation are listed and addressed.
- User-facing wording aligns to goal-first semantics.
- Deprecation notes are captured in docs.

## Dependencies
- ACP-601

## Validation
- String audit and targeted regression checks.
