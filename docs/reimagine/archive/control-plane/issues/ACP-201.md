# ACP-201: Implement planner service

## Problem
Goals cannot be executed coherently until a planner decomposes them into structured work.

## Scope
- Implement a planner service that decomposes goals into steps, dependencies, and checkpoints.
- Persist planner outputs in goal-linked records.
- Keep planner execution separate from runtime step execution.

## Out of Scope
- Agent provider implementation details.
- Full UI implementation beyond data contracts.

## Acceptance Criteria
- A goal can produce a concrete plan.
- Plan output includes ordered steps, dependencies, and checkpoints.
- Planner output can be saved and reloaded.

## Dependencies
- ACP-101

## Validation
- Unit tests for planner decomposition and plan shape.
