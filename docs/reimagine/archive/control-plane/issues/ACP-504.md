# ACP-504: Preserve existing workflow explorers

## Problem
Transition risk increases if current Loops, Runs, and Evidence explorers break while goal-first surfaces are added.

## Scope
- Keep existing explorers available during migration.
- Ensure new goal features do not regress old explorer behavior.
- Document coexistence behavior.

## Out of Scope
- Immediate removal of existing explorers.
- Major explorer redesign.

## Acceptance Criteria
- Loops, Runs, and Evidence views remain functional.
- Goal-first additions do not break current workflows.
- Coexistence behavior is documented.

## Dependencies
- ACP-205

## Validation
- Regression tests for existing explorer commands and actions.
