# ACP-303: Separate claims from evidence

## Problem
Agent or planner assertions must not be conflated with objective artifacts.

## Scope
- Define a claim record model distinct from evidence records.
- Ensure claims can reference supporting evidence.
- Preserve independent storage and retrieval paths for claims and facts.

## Out of Scope
- Claim scoring or trust heuristics.
- Advanced UI filtering.

## Acceptance Criteria
- Claims and evidence are stored as separate record types.
- Claims can reference supporting evidence IDs.
- No code path overwrites evidence with claim content.

## Dependencies
- ACP-302

## Validation
- Tests proving claims and evidence remain separate in persistence and APIs.
