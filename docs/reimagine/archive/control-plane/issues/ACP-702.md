# ACP-702: Expand manual validation

## Problem
Some supervisory and UX behaviors cannot be fully validated through automated tests alone.

## Scope
- Add manual validation scenarios for goal creation, planning visibility, blocking, and evidence traceability.
- Align manual checks with stage exit gates.
- Capture expected evidence for pass/fail results.

## Out of Scope
- Automated UI test framework rollout.
- End-user training material.

## Acceptance Criteria
- Manual test matrix includes core control-plane UX checks.
- Validation instructions are reproducible.
- Manual results can be mapped to tracker stage gates.

## Dependencies
- ACP-501, ACP-502, ACP-503

## Validation
- Manual runbook review and dry-run completion for key flows.
