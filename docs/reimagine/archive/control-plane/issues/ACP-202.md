# ACP-202: Add progress evaluation and replanning

## Problem
Static plans become stale when evidence changes, checks fail, or constraints block execution.

## Scope
- Implement progress evaluation that updates goal progress from evidence.
- Add replanning paths when checkpoints fail or policy blocks execution.
- Append checkpoint history and reasons for plan changes.

## Out of Scope
- Final UX presentation.
- Policy engine internals.

## Acceptance Criteria
- Progress updates are derived from evidence and planner state.
- Replanning preserves prior plan history.
- Replanning reasons are persisted and inspectable.

## Dependencies
- ACP-201, ACP-105

## Validation
- Unit tests for progress transitions and replanning triggers.
