# ACP-105: Add structured progress tracking

## Problem
Progress must be visible, durable, and explainable if the system is going to supervise real engineering work.

## Scope
- Add a structured progress record to the goal model.
- Persist progress state, checkpoints, reasons, timestamps, and evidence links.
- Make progress updates derived from planner output and evidence rather than narration alone.

## Out of Scope
- Full planner implementation.
- Full goal-centric UI redesign.

## Acceptance Criteria
- Progress can be queried as a structured record.
- Progress history shows why the value changed.
- Evidence links are attached to progress updates.

## Dependencies
- ACP-101, ACP-102

## Validation
- Tests for progress record updates and persisted history.
