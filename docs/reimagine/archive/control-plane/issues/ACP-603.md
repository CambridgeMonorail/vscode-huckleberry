# ACP-603: Preserve historical runs and evidence

## Problem
Historical execution context must remain accessible after goal-first changes are introduced.

## Scope
- Ensure legacy run and evidence records remain readable.
- Add migration-safe adapters where formats diverge.
- Keep provenance links intact.

## Out of Scope
- Full migration of all historical data to new schema.
- External archival systems.

## Acceptance Criteria
- Historical runs can still be inspected.
- Historical evidence links resolve where artifacts exist.
- Compatibility behavior is documented.

## Dependencies
- ACP-302, ACP-303

## Validation
- Compatibility tests against representative legacy run/evidence samples.
