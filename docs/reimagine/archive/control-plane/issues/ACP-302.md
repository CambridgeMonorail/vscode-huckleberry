# ACP-302: Expand evidence model

## Problem
The existing artifacts are useful but the control plane requires broader, goal-linked evidence coverage.

## Scope
- Expand evidence types to include compiler output, diagnostics, tests, screenshots, diffs, scans, and summaries.
- Link evidence records to goals, plans, and steps.
- Capture provenance metadata for each artifact.

## Out of Scope
- External evidence storage systems.
- Full evidence search UX.

## Acceptance Criteria
- Evidence artifacts are typed and persisted with provenance.
- Artifacts can be traced to goal and step origin.
- Existing artifact paths remain compatible.

## Dependencies
- ACP-201

## Validation
- Tests for evidence typing, persistence, and linkage.
