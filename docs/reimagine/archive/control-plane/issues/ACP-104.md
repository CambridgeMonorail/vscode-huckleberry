# ACP-104: Introduce basic goal commands

## Problem
Users need a command path to work with goals before the goal-centric UI is complete.

## Scope
- Add commands to create, list, inspect, pause, resume, and close goals.
- Wire commands to goal services.
- Keep command names aligned with the goal model.

## Out of Scope
- Planner implementation.
- New explorer views.

## Acceptance Criteria
- Goals can be managed from the Command Palette.
- Commands use the lifecycle service rather than duplicating logic.
- Commands expose goal state clearly.

## Dependencies
- ACP-102, ACP-103

## Validation
- Command registration and command-handler tests.
