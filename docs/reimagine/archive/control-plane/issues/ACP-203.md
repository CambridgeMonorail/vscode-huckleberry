# ACP-203: Add supervisory progress reporting

## Problem
Progress data is not useful unless supervisory surfaces can expose it clearly.

## Scope
- Add service hooks for progress updates.
- Expose progress snapshots to command and view consumers.
- Include status signals for advancing, blocked, and regressing progress.

## Out of Scope
- Full goal explorer implementation.
- New policy behavior.

## Acceptance Criteria
- Progress updates are available to UI surfaces.
- Progress reporting includes latest reason and evidence references.
- Supervisory views can read progress without parsing raw logs.

## Dependencies
- ACP-202

## Validation
- Integration tests for progress reporting APIs.
