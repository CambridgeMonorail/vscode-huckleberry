# ACP-701: Expand automated tests

## Problem
Core control-plane behaviors need deterministic test coverage before release gating is meaningful.

## Scope
- Expand tests for goals, planning, policy, evidence, claims, and orchestration.
- Add coverage for progress record updates and state transitions.
- Ensure tests run within existing validation lanes.

## Out of Scope
- Load testing.
- Non-deterministic model quality scoring.

## Acceptance Criteria
- Critical control-plane paths have automated coverage.
- Test suite remains stable in CI.
- Coverage gaps are documented where deferred.

## Dependencies
- ACP-202, ACP-301, ACP-302, ACP-404

## Validation
- `pnpm validate:affected` and focused extension tests pass.
