# ACP-004: Record validation contract

## Problem
The roadmap needs a clear rule for when a stage is done and how progress is measured while work is in flight.

## Scope
- Define automated validation expected for each stage.
- Define manual validation expected for each stage.
- Define what evidence is required to mark progress as complete.

## Out of Scope
- Implementation of any validation jobs.

## Acceptance Criteria
- Validation contract covers automated and manual checks.
- Stage exit criteria map cleanly to the tracker.
- Progress reporting expectations are explicit.

## Dependencies
- ACP-001

## Validation
- Review the contract against the staged implementation plan and tracker.
