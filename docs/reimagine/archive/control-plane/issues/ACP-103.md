# ACP-103: Add goal persistence and hydration

## Problem
Goal state must survive reloads and branch changes if the repository is the durable memory.

## Scope
- Persist active and historical goals in workspace files.
- Hydrate goal records back into runtime state.
- Preserve goal history across restarts.

## Out of Scope
- Planner or policy behavior.
- UI presentation details.

## Acceptance Criteria
- Goals can be saved and restored from the workspace.
- History survives reload.
- Persistence format is documented or discoverable in code.

## Dependencies
- ACP-101

## Validation
- Round-trip persistence tests for goal records.
