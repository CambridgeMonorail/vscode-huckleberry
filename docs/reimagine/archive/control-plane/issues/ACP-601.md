# ACP-601: Map workflows to goals

## Problem
Current workflow assets need a path into the goal-first model to avoid forcing immediate rewrites.

## Scope
- Define mapping rules from workflow definitions to goal seeds.
- Support import or compatibility conversion paths.
- Preserve traceability from imported goals back to original workflow files.

## Out of Scope
- Automatic semantic migration of every historical run.
- Removal of existing workflow formats.

## Acceptance Criteria
- Existing workflows can initialize goals.
- Mapping behavior is deterministic and documented.
- Source workflow references are retained.

## Dependencies
- ACP-101, ACP-205

## Validation
- Integration tests for workflow-to-goal mapping scenarios.
