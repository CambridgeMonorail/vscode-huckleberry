# ACP-604: Add compatibility tests

## Problem
Migration confidence is low without explicit tests for old and new behavior coexisting.

## Scope
- Add regression coverage for workflow-first and goal-first paths.
- Cover persistence hydration, explorer behavior, and evidence access.
- Include representative migration boundary scenarios.

## Out of Scope
- Performance benchmarking suite.
- End-user acceptance testing scripts.

## Acceptance Criteria
- Compatibility tests pass in CI.
- Key migration boundaries are covered.
- Failures identify whether regression is in old path, new path, or bridge layer.

## Dependencies
- ACP-601, ACP-603

## Validation
- Test suite execution with coverage of compatibility scenarios.
