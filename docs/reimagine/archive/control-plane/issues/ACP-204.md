# ACP-204: Add supervision state tracking

## Problem
Goal execution cannot be controlled safely without explicit supervisory states.

## Scope
- Implement canonical states: queued, running, paused, blocked, failed, exhausted, completed.
- Store transitions with timestamps and reasons.
- Expose state transitions through runtime APIs.

## Out of Scope
- UI styling of state badges.
- Agent-specific orchestration behavior.

## Acceptance Criteria
- Runtime can transition goals through canonical states.
- Invalid transitions are rejected.
- Transition history is persisted and reloadable.

## Dependencies
- ACP-201

## Validation
- State-machine tests for valid and invalid transitions.
