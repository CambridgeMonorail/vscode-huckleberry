# ACP-404: Add agent assignment and claim tracking

## Problem
Goal supervision needs explicit records of which agent performed what work and what they claimed.

## Scope
- Record agent assignment metadata per goal step.
- Persist claim records linked to assignments and evidence.
- Surface assignment outcomes to supervisory APIs.

## Out of Scope
- UI dashboards for per-agent analytics.
- Dynamic agent market bidding.

## Acceptance Criteria
- Agent assignment metadata is persisted.
- Claims are linked to agent assignments and evidence references.
- Assignment outcomes are retrievable by goal and step.

## Dependencies
- ACP-303, ACP-403

## Validation
- Tests for assignment records and claim linkage integrity.
