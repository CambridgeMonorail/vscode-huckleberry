# ACP-101: Define Goal schema and model

## Problem
The control plane needs a durable primary work unit before planning, policy, and UI can be built on top of it.

## Scope
- Define the Goal schema and TypeScript model.
- Include description, acceptance criteria, status, progress, plan, evidence, and history.
- Make the model suitable for workspace persistence.

## Out of Scope
- Planner logic.
- UI implementation.

## Acceptance Criteria
- Goal model can be serialized and deserialized.
- Goal model includes the fields required by the requirements doc.
- Goal model supports persisted history entries.

## Dependencies
- ACP-001

## Validation
- Schema review and model review against requirements.
