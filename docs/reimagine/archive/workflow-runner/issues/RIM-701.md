# RIM-701: Expand test suite for critical run lifecycle paths

## Problem
Core workflow reliability is at risk without comprehensive test coverage of run lifecycle and failure handling.

## Scope
- Expand unit and integration tests for runner and extension critical paths.
- Add smoke tests covering stage-critical scenarios.
- Establish minimum coverage target for key modules.

## Out of Scope
- Full end-user scenario matrix for every plugin permutation.
- Non-critical cosmetic UI test expansion.

## Acceptance Criteria
- Critical run lifecycle paths are covered by automated tests.
- Regressions in stop reasons, retries, and persistence are caught by tests.
- Coverage target for critical modules is met.

## Dependencies
- RIM-306, RIM-404, RIM-504, RIM-604

## Validation
- CI run demonstrates passing expanded test suite.
- Coverage report confirms threshold for critical modules.
