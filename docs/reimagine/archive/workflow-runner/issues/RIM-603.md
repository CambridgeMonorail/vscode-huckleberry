# RIM-603: Add isolation visibility in UI

## Problem
Users cannot safely review isolated runs without clear visibility into worktree context and branch location.

## Scope
- Show isolation mode, worktree path, and branch details in run UI.
- Add affordances to open worktree location and inspect branch status.
- Display warnings when isolation metadata is missing or stale.

## Out of Scope
- Full git client implementation.
- Advanced branch management features.

## Acceptance Criteria
- Run details clearly show whether execution used workspace or worktree.
- Worktree path and branch metadata are accessible from UI.
- Missing metadata states are clearly communicated.

## Dependencies
- RIM-602, RIM-305

## Validation
- Manual isolated run walkthrough validates metadata display.
- UI tests for visibility and warning states.
