# RIM-402: Implement Copilot adapter (preview-safe)

## Problem
Agent repair steps require a first concrete provider integration, but provider APIs can change and fail.

## Scope
- Implement Copilot-backed adapter behind `AgentAdapter` interface.
- Add capability probing and startup availability checks.
- Add graceful error mapping from provider failures to run stop reasons.

## Out of Scope
- Additional provider integrations.
- Advanced provider-specific optimization.

## Acceptance Criteria
- Adapter can execute bounded agent requests through provider integration.
- Unavailable provider or API failure produces explicit, non-corrupt run failure path.
- Adapter can be toggled off without breaking command-only workflows.

## Dependencies
- RIM-401

## Validation
- Integration test for successful agent step execution via adapter.
- Failure-path tests for unavailable provider and adapter runtime exceptions.
