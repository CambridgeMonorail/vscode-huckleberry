# RIM-702: Add resilience and recovery testing

## Problem
Crash and reconnect scenarios can silently corrupt user trust if recovery behavior is untested.

## Scope
- Add tests for runner crash, extension reload, and reconnect handling.
- Verify event replay reconstructs state after interruption.
- Define recovery expectations and failure modes.

## Out of Scope
- Distributed multi-machine recovery.
- External database failover testing.

## Acceptance Criteria
- Interrupted runs recover to known and consistent state.
- Recovery behavior is deterministic for tested fixtures.
- Recovery failures include explicit diagnostics.

## Dependencies
- RIM-304, RIM-701

## Validation
- Automated recovery test scenarios pass consistently.
- Manual smoke test for extension reload during active run.
