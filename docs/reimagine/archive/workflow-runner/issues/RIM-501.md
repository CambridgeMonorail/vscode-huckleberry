# RIM-501: Implement approval gate step

## Problem
Subjective decisions need explicit human input, but current flow has no formal pause and resume gate.

## Scope
- Implement `approval` step behavior in runner lifecycle.
- Add approve, reject, and defer actions.
- Persist approval decisions and actor metadata.

## Out of Scope
- Multi-approver policy engine.
- External approval system integrations.

## Acceptance Criteria
- Runs pause at approval steps and do not continue without explicit action.
- Approve, reject, and defer actions are recorded and auditable.
- Resume behavior follows configured branch semantics.

## Dependencies
- RIM-302, RIM-304

## Validation
- Integration tests for approve, reject, and defer paths.
- Manual UI flow confirms paused run can be resumed correctly.
