# RIM-204: Implement LoopExplorerProvider

## Problem
Users need a dedicated workflow list with validation status to inspect readiness before execution.

## Scope
- Implement loop explorer tree provider backed by discovery service.
- Display loop validity and status badges (valid or invalid).
- Add open-definition and refresh interactions.

## Out of Scope
- Run timeline view implementation.
- Evidence explorer.

## Acceptance Criteria
- Loop list renders discovered workflows with status indicators.
- Selecting an item opens workflow definition and validation details.
- Refresh action re-queries discovery and updates tree state.

## Dependencies
- RIM-202, RIM-203

## Validation
- Manual UI walkthrough in extension host.
- Provider tests verify mapping from discovery plus validation results to tree items.
