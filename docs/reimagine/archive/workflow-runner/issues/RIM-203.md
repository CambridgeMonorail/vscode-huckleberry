# RIM-203: Build workflow validator service

## Problem
Schema-only validation is insufficient for semantic correctness, causing runtime errors later in execution.

## Scope
- Implement validation pipeline for schema and semantic checks.
- Add semantic checks for unresolved step references and invalid condition targets.
- Provide normalized validation result model for UI and command consumers.

## Out of Scope
- Runner execution logic.
- Autofix of invalid workflows.

## Acceptance Criteria
- Validator reports schema and semantic issues in a single response model.
- Semantic errors include file path, location where available, and human-readable guidance.
- Invalid workflows are clearly marked for explorer consumers.

## Dependencies
- RIM-201

## Validation
- Fixture suite covers schema and semantic failure modes.
- UI or command surface can present validator output without custom parsing.
