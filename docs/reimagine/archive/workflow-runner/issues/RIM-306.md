# RIM-306: Add cancellation and failure-stop reason model

## Problem
Ambiguous stopping behavior undermines trust and makes troubleshooting difficult.

## Scope
- Implement explicit cancellation controls and propagation to runner.
- Define machine-readable stop reason codes and human-readable messages.
- Ensure non-success terminal outcomes include structured reason payload.

## Out of Scope
- Policy-based approval flow logic.
- Agent-specific stop reason categories beyond generic contract.

## Acceptance Criteria
- Users can cancel active runs reliably from extension UI.
- Every non-success terminal run includes reason code and message.
- Stop reasons are visible in runs timeline and retrievable via API/model.

## Dependencies
- RIM-302

## Validation
- Cancellation integration tests for running command step.
- Fixture tests for each non-success terminal outcome.
