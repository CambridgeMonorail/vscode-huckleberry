# RIM-405: Separate agent claims from objective evidence

## Problem
If agent narrative and objective artifacts are mixed, users cannot clearly assess trustworthiness of run outcomes.

## Scope
- Extend run data model to store agent claims separately from evidence artifacts.
- Update timeline/details presentation to distinguish claim vs fact.
- Ensure summaries preserve distinction in generated output.

## Out of Scope
- Full Evidence Explorer implementation details.
- Additional claim adjudication logic.

## Acceptance Criteria
- Agent-generated text is stored in dedicated claim structures.
- Deterministic outputs remain in evidence structures with provenance.
- UI clearly labels claims vs evidence for each relevant step.

## Dependencies
- RIM-304, RIM-403

## Validation
- Data-model tests for claim/evidence separation.
- UI tests confirm labels and sections are distinct.
