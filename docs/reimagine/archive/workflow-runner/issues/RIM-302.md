# RIM-302: Implement state-machine engine

## Problem
Without deterministic step transitions, workflow runs are not reproducible or debuggable.

## Scope
- Implement sequential execution state machine.
- Add condition branching, retry handling, timeout handling, and terminal transitions.
- Define transition event payloads for persistence and UI projection.

## Out of Scope
- Agent provider details.
- Advanced parallel branching.

## Acceptance Criteria
- State transitions are deterministic for identical inputs.
- Retry and timeout rules are enforced according to workflow config.
- Terminal states include clear transition reasons.

## Dependencies
- RIM-301

## Validation
- Unit tests for transition table and edge cases.
- Replay test confirms same event sequence for same fixtures.
