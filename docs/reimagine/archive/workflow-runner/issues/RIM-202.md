# RIM-202: Add .huckleberry/loops discovery service

## Problem
Workflows are not useful if the extension cannot discover and refresh definitions from repository files.

## Scope
- Implement workflow discovery under `.huckleberry/loops`.
- Add file watch behavior for add/update/delete events.
- Expose discovery results to loop explorer provider.

## Out of Scope
- Workflow execution.
- Full evidence explorer integration.

## Acceptance Criteria
- Loops are discovered from repository file system on startup.
- Add, edit, and delete operations are reflected in UI without restart.
- Discovery failures are surfaced with actionable messages.

## Dependencies
- RIM-201

## Validation
- Manual test with create/edit/delete loop files.
- Automated tests for discovery and watcher refresh behavior.
