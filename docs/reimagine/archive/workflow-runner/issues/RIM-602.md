# RIM-602: Route command and agent steps through isolation context

## Problem
Isolation mode is incomplete unless all execution paths can run consistently in workspace or worktree context.

## Scope
- Implement execution context abstraction for workspace and worktree modes.
- Route command and agent step executors through context boundary.
- Ensure context details are propagated to evidence and event metadata.

## Out of Scope
- Policy engine for automatic mode selection.
- Cross-host remote execution.

## Acceptance Criteria
- Same workflow definition can run in workspace or worktree mode.
- Command and agent steps use selected context reliably.
- Context metadata is visible in run records.

## Dependencies
- RIM-601, RIM-403

## Validation
- Integration tests for both context modes using same fixture workflow.
- Manual verification of generated artifacts in expected location.
