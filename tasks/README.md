# Legacy Task Data

The original Huckleberry task-manager records have been moved to [`archive/2025-task-manager`](./archive/2025-task-manager/). They are preserved as historical data and are not an active engineering backlog.

The active Huckleberry reimagination plan is maintained in:

- [`docs/reimagine/PLAN.md`](../docs/reimagine/PLAN.md)
- [`docs/reimagine/issues/README.md`](../docs/reimagine/issues/README.md)

Do not add new `TASK-*` records here. New implementation work should use the `LOOP-*` specifications until the project adopts an external issue tracker as its source of truth.
